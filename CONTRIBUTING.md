# Contributing

Thanks for helping improve H2S Open Source Radar.

## Development

1. Use Python 3.10+ on macOS.
2. Create a virtual environment.
3. Install `requirements-dev.txt`.
4. Run `python app.py`.
5. Keep privacy-sensitive features opt-in and document any new local data source.

## Pull requests

- Keep changes focused.
- Do not add telemetry, keystroke capture, screenshots, clipboard monitoring, or
  file-content indexing as a default behavior.
- Add or update license notices when adding dependencies.
- Never commit API tokens, credentials, local databases, or user paths that
  expose private data.

By contributing, you agree that your contribution is licensed under Apache-2.0.
